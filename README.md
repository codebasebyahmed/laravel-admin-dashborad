## ✨ المميزات الرئيسية (Key Features)

- 🎨 **تصميم عصري ونظيف:** واجهة مستخدم مريحة للعين مبنية بالكامل باستخدام **Tailwind CSS**.
- 🌍 **دعم كامل للاتجاهين (RTL & LTR):** تهيئة مسبقة لدعم اللغة العربية (من اليمين لليسار) واللغة الإنجليزية (من اليسار لليمين) بسلاسة تامة.
- 🧩 **سهولة الدمج والنقل (Plug & Play):** تم تقسيم ملفات `Blade` بشكل منظم ومستقل يسهل عليك نسخها ودمجها في أي مشروع Laravel قائم دون تعقيد.
- 📱 **متجاوب 100% (Fully Responsive):** يعمل بكفاءة على جميع أحجام الشاشات (الهواتف، الأجهزة اللوحية، وشاشات سطح المكتب).
- ⚡ **أداء فائق:** خالٍ من المكتبات الثقيلة غير الضرورية لضمان سرعة التحميل.

## 🚀 طريقة التثبيت والدمج في مشروعك (Installation & Integration)

يمكنك نقل التصميم إلى مشروعك الحالي باتباع الخطوات البسيطة التالية:

### 1. نسخ الملفات (Copy Files)

- انسخ مجلدات الواجهات من `resources/views/` (مثل `layouts` و `components` وصفحات الداشبورد) إلى مشروعك.
- انسخ ملفات التنسيق والسكربتات من مجلد `resources/css/` و `resources/js/`.

### 2. تثبيت الحزم وتشغيل Tailwind (Install Dependencies)

تأكد من تثبيت حزم Node.js وتشغيل أمر البناء في مشروعك:

```bash
npm install
npm run dev
```

### 3. تشغيل المشروع (Run Server)

```bash
php artisan serve
```
